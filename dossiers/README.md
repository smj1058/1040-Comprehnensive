# `dossiers/` — local mirror of `G:\Shared drives\_SMJ\___Product Development\ExecSumm-Emails\dossiers\`

Every refresh writes two copies of the comprehensive client dossier:

1. **Drive** — the canonical source of truth at the path above.
2. **This folder** — the local/repo mirror, committed for PR review and as a
   fallback if Drive access is offline.

Filenames use the pattern:

```
<Client>_Client_Intelligence_<YYYY-MM-DD>.md
```

Prior dated files are **retained forever** — the cumulative / living-document
rules require that history be preserved so a reader can see how the narrative
and facts evolved over time.

- `SpringBengtzen_Client_Intelligence_2026-04-22.md`
- `TommyHarr_Client_Intelligence_2026-04-22.md`

Both are also mirrored into the matching Executive Summaries DB rows in Notion.
